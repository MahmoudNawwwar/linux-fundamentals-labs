-
[root@localhost test]# useradd -u 2080 aliaa

2- Grant access to user Alia so that it can run any command without a password.

5-Switch to user Alia and create user Arya. Also create user Jon with comment "winter is coming", and user Tyrion.

[root@localhost test]# su aliaa

6-With user Alia, create group starks and lannisters.
-
[aliaa@localhost test]$ sudo groupadd starks
[aliaa@localhost test]$ sudo groupadd lannisters
-

7-With user Alia, create directory gameofthrones
-
[aliaa@localhost test]$ mkdir gameofthrones
-
8- Under gameofthrones , create 2 subdirectories starks and lannisters
-
[aliaa@localhost test]$ mkdir gameofthrones
[aliaa@localhost test]$ cd gameofthrones
[aliaa@localhost gameofthrones]$ mkdir starks lannisters
[aliaa@localhost gameofthrones]$ ls
lannisters  starks

9-Change ownership of directory stark so the owner is Arya and group is starks, while the user owner of directory lannisters is Tyrion and group owner is lannisters.
-
[aliaa@localhost gameofthrones]$ sudo chown Arya:starks starks
[aliaa@localhost gameofthrones]$ sudo chown Tyrion:lannisters lannisters
-
10-Ensure any subdirectory to inherit the group ownership from the parent directory for /starks
